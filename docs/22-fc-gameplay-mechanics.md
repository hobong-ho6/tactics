> 이 문서는 docs/20의 연장이다. **docs/20이 다루는 것은 Roles(오프더볼) — 우리 커널이 직접 대응하는 층**이고,
> 이 문서가 다루는 것은 **PlayStyles(온더볼) + 6대 스탯 + 조작 체계** — 커널이 대응하지 못하는 나머지 층이다
> (docs/20 「대상 시스템의 구조」: *선수 행동 = OVR + HyperMotion + PlayStyles(온더볼) + Roles(오프더볼)*).
> `player_game_stats.playstyles` 컬럼에 이미 문자열로 수집 중인 값을 해석할 때 이 문서를 참조한다.
> 정본 EA 원문은 docs/20의 「EA 공식 피치노트」 절과 같은 원칙으로 — 2차 가이드와 충돌하면 EA 1차가 이긴다.

# FC26 게임플레이 메커니즘 — PlayStyles·스탯·조작 (2026-09-02 신설)

## 1. 조작 체계 — 이동 속도 3단계

| 속도 | 트리거 |
|---|---|
| **걷기** | 왼쪽 스틱을 살짝만 기울임 |
| **조깅** | 왼쪽 스틱을 끝까지 기울이되 **스프린트 버튼은 누르지 않음** |
| **스프린트** | 왼쪽 스틱을 끝까지 기울이고 **R2/RT(스프린트)를 동시에 누름** |

⭐ 여러 PlayStyle(대표적으로 Press Proven)의 발동 조건이 "조깅 속도"로 명시돼 있다 — **스프린트 버튼을
떼면 조깅 상태**이므로, 근접 컨트롤·쉴딩 계열 PlayStyle을 쓸 때는 스프린트를 참는 것이 핵심이다.

### 모디파이어 버튼(상황에 따라 공격/수비 의미가 바뀜, Xbox 기준 · PS는 괄호)

| 버튼 | 공격 시 | 수비 시 |
|---|---|---|
| RB(R1) | 피네스 모디파이어 · 스프린트/근접 컨트롤 | 동료 압박 지시(Teammate Contain) |
| LB(L1) | 오버래핑 런/트리거 런 | 선수 전환(Switch Player) |
| LT(L2) | 정밀 드리블·쉴딩 | 조키(Jockey, 크랩스텝 견제) |
| RT(R2) | 피네스 무브·고속 스프린트 | LT+RT 동시 = 고속 조키 |

- **피네스 슛**: B+RB(○+R1). **로우드리븐 피네스**(변형): RB/R1 홀드 후 슛 더블탭.
- **쉴딩**: LT/L2 홀드로 몸을 볼과 수비수 사이에 넣는다. 가만히 버티기보다 **급턴·볼 굴리기와 결합**할 때 효과가 크다.
- **LT+RB(L2+R1) 슬로우 드리블+급턴**: 쉴딩을 유지한 채 방향 전환 — 프레스 프루븐 보유 선수가 특히 잘 듣는다.
- 게임플레이 프리셋 2종: **Competitive**(빠른 패스·정밀 드리블 — 온라인 UT/클럽 기본) vs **Authentic**(느리고
  사실적 — 오프라인 커리어 기본). 같은 스탯·PlayStyle이라도 프리셋에 따라 체감이 다르다.

## 2. 6대 스탯 — 무엇을 결정하는가

카드에 보이는 6대 종합 스탯은 **30개 이상 세부 속성의 가중 평균**이다. 포지션마다 OVR 가중치가 달라
(예: CB는 수비+피지컬 비중이 크고, 윙어는 스피드+드리블 비중이 큼) 세부 속성을 봐야 실제 플레이 스타일이 보인다.

| 종합 스탯 | 결정하는 것 | 주목할 세부 속성 |
|---|---|---|
| **PAC(스피드)** | 전력질주 속도 + 최고속도 도달 시간. 다른 스탯(드리블·포지셔닝)의 승수처럼 작동 — 빠른데 드리블도 좋으면 시너지 | 가속력(정지→최고속 도달 시간) · 질주속도(최고속) |
| **SHO(슈팅)** | 득점 확률 전반 | **결정력**은 박스 안 발슛 정확도만 결정 — 헤더·중거리는 별도 |
| **PAS(패싱)** | 빌드업·전환 정확도 | **시야**(패스 선택지 인식) · 크로스 · 단短패스 · 장長패스는 서로 독립 |
| **DRI(드리블)** | 볼을 몸에 붙이는 능력(뺏기 어려움). 스킬무브 별점과는 **별개 축** | **침착(Composure)**은 드리블 하위 속성이지만 골 결정 순간의 냉정함을 좌우 |
| **DEF(수비)** | 볼 따내기 능력 | **수비 위치선정**이 실질 1티어 — 위치선정이 좋으면 태클 자체가 줄어든다. **적극성**은 반칙·PK 리스크와 트레이드오프 |
| **PHY(피지컬)** | 몸싸움·지구력·공중볼 | 힘·체력·점프력 등이 개별 작동 |

- **OVR은 포지션별 가중 평균**이라, 스피드 극단으로 높은데 패스가 약한 윙어는 OVR이 생각보다 낮게 나올 수 있고
  반대로 수비+피지컬만 강한 CB는 스피드가 평범해도 OVR이 높게 나온다.
- **AcceleRATE(가속 유형)**은 docs/20 §⑤(EA 공식 공식표)가 정본 — 이 문서에서 중복 서술하지 않는다.

## 3. PlayStyles 전체 카탈로그 (FC26, 6카테고리 35종)

⭐ **공통 원칙**: PlayStyle은 대부분 **패시브**다 — 별도 버튼 콤보가 아니라 "그 상황(조깅 속도로 드리블 중,
쉴딩 중, 슬라이딩 태클 시도 중 등)에서 자동으로 보정치가 얹히는 방식"이다. **+(플러스) 버전은 효과가
과장된 수준으로 강화**되며, 실존 선수의 특출난 능력치를 반영해 EA가 부여한다(공식 미공개 수치).
아래는 각 PlayStyle의 **발동 상황**과 **효과**를 정리한 것 — 발동을 위해 사용자가 직접 눌러야 하는
입력이 있으면 별도 표기했다.

### 파이널서드(득점) — Scoring

| PlayStyle | 발동 상황 | 효과 |
|---|---|---|
| Finesse Shot | 피네스 슛 입력(RB/R1 + 슛) | 슛 속도·정확도·커브 향상 |
| Low Driven Shot | 로우드리븐 슛(RB/R1 홀드+슛 더블탭) | 저구간 강슛의 속도·정확도 향상 |
| Power Shot | 파워샷(슛 버튼 길게 충전) | 빌드업 속도·정확도 대폭 향상 |
| Chip Shot | 칩 슛(LB/L1+슛) | 칩 슛 속도·정밀도 향상 |
| Acrobatic | 발리 상황 | 발리 정확도 향상 + 전용 아크로바틱 애니메이션 |
| Precision Header | 헤더 상황(점프력 자체는 불변) | 헤더 정확도 향상 + 전용 애니메이션 |
| Gamechanger | 트리벨라(바깥발) 슛·화려한 슛 | 트리벨라 슛 활성화 + 정확도 향상 |
| Dead Ball | 세트피스(프리킥·코너) | 세트피스 속도·정확도·파워 향상, 궤적 프리뷰 강화 |

### 패스 — Passing

| PlayStyle | 발동 상황 | 효과 |
|---|---|---|
| Pinged Pass | 모든 패스 유형 | 패스 속도 상승 + 동료가 받기 쉬워짐(트래핑 보정) |
| Incisive Pass | 스루패스·정밀패스·감아차기패스 | 스루패스 정확도·정밀패스 속도·감아차기 커브 향상 |
| Long Ball Pass | 롱볼·로빙패스 | 정확도·속도 향상 + 인터셉트 당할 확률 감소 |
| Whipped Pass | 크로스 | 정확도·속도·커브 향상 |
| Tiki Taka | 원터치·단패스 상황 | 첫터치·단패스 정확도 향상 + 조건 충족 시 자동 백힐 |
| Inventive | 화려한 패스(스루패스 변형 등) | 정확도 향상 + 전용 애니메이션 |

### 볼 컨트롤 — Ball Control

| PlayStyle | 발동 상황 | 효과 |
|---|---|---|
| **Press Proven** | **조깅 속도로 드리블 중** (스프린트 버튼 안 누름) | 근접 컨트롤 대폭 향상 + 피지컬 압박에 대한 쉴딩 효율 상승 |
| First Touch | 패스를 받는 순간 | 트래핑·첫 드리블 개시 속도 향상(터치가 가벼워짐) |
| Rapid | **스프린트 중** 드리블 | 온볼 스프린트 속도 향상 + 스프린트/노크온 시 실수 확률 감소(Press Proven의 정반대 축 — 조깅 vs 스프린트) |
| Technical | 넓은 회전 드리블 | 컨트롤드 스프린트 속도·와이드턴 정밀도 향상 |
| Trickster | 스킬무브 입력 | 전용 스킬무브(Trickster Fake Shot 등) 해금 |

### 수비 — Defending

| PlayStyle | 발동 상황 | 효과 |
|---|---|---|
| Jockey | 조키(LT+RT/L2+R2) | 스프린트 조키·전환 속도 향상 |
| Block | 슛/패스 블록 시도 | 블록 범위·성공률 향상 |
| Intercept | 인터셉트 성공 시 | 인터셉트 리치 향상 + 성공 후 볼 소유 유지력 상승 |
| Anticipate | 스탠딩 태클 시도 | 스탠딩 태클 성공률 향상 + 태클 후 발밑에 볼을 세우는 능력 |
| Slide Tackle | 슬라이딩 태클 시도 | 슬라이딩 태클 효율 향상 + 태클 후 볼 컨트롤 유지 |
| Aerial Fortress | 공중볼 경합 | 점프력·공중 지배력(경합 승률) 향상 |

### 피지컬 — Physical

| PlayStyle | 발동 상황 | 효과 |
|---|---|---|
| Bruiser | 몸싸움 태클 | 상대를 몸으로 밀어내며 볼을 빼앗는 능력 향상 |
| Enforcer | 어깨싸움(숄더 챌린지)·쉴딩 | 숄더 챌린지 활성화 + 쉴딩 능력 대폭 향상(피지컬형 공격수의 "뺏기지 않는" 축) |
| Quick Step | 익스플로시브 스프린트 진입 순간 | 초반 가속력 향상 |
| Relentless | 지속 압박·contain 전술 | 스태미나 회복 향상 + 압박 지속 시간 연장 |
| Long Throw | 스로인 | 스로인 파워·최대 거리 향상 |

### 골키퍼 — Goalkeeping

| PlayStyle | 발동 상황 | 효과 |
|---|---|---|
| Far Reach | 원거리 선방(다이빙) | 다이빙/점프 애니메이션 다양화 + 박스 밖 슛 대응력 향상 |
| Footwork | 발밑 선방 | 풋세이브 성능 향상 + 전용 애니메이션 |
| Cross Claimer | 크로스 캐칭 | 크로스 차단 속도 향상 + 전용 캐칭 애니메이션 |
| Rush Out | 박스 밖 스위핑(전진 저지) | 박스 밖으로 뛰쳐나가는 속도 향상 + 반사/예측 전용 애니메이션 |
| Deflector | 슛 저지(막지 못하는 상황) | 쳐낸 볼이 위험 지역이 아니라 안전한 곳(동료 쪽)으로 향하도록 보정 + 전용 애니메이션 |
| Far Throw | 골킥/배급 | 스로 파워·거리 향상 |

⚠️ FC26에서 **Trivela·Flair·Power Header·Aerial 4종이 폐지**되고 **Enforcer 등 5종으로 재구성**됐다 —
전작(FC25) 자료를 그대로 인용하지 말 것.

## 4. 활용 팁 — 대표 조합

- **박스투박스 CM**: Pinged Pass + Press Proven 조합이 표준(전진 배급 + 압박 버티기).
- **풀백(RB/LB)**: Bruiser+ (몸싸움) + Intercept+ + Quick Step+ + Pinged Pass+가 상위 빌드의 공통축.
- **스트라이커**: Finesse Shot+·Low Driven+가 핵심, Tiki Taka·First Touch·Quick Step·Gamechanger가 기본 세트.
- **골키퍼**: 롤(라인골키퍼/볼플레잉/스위퍼) 불문 Cross Claimer+·Far Reach+가 공통 상위 픽, Footwork·Deflector·
  Rush Out·Pinged Pass·Long Ball이 기본 세트.
- ⚠️ **FC26은 전작 대비 쉴딩 자체가 약화**됐다는 커뮤니티 평가가 많다(자연 쉴딩 판정 약화로 상대가 더 쉽게
  볼을 빼앗음) — Press Proven·Enforcer 미보유 선수의 볼 운반 시 상대와의 거리를 더 벌리는 식으로 보완할 것.

## 5. DB 반영 규칙

- `player_game_stats.playstyles`에 수집된 문자열은 **선수명·시즌 스냅샷별 실제 보유 목록**이지, 이 문서의
  카탈로그와 별개 축이다. 이 문서는 **해석용 참고자료**이고 선수별 보유 현황은 DB가 정본이다.
- 이 문서 자체는 **커널(Role/오프더볼) 판정에 쓰지 않는다** — PlayStyles는 온더볼 층이라 docs/20의
  코사인 유사도 계산 대상이 아니다(불변규칙 혼동 주의).
- 새 시즌(FC27 등)에서 PlayStyles 목록·효과가 바뀌면 **이 문서에 새 절을 추가**한다(불변규칙 2 — 기존 표는
  두고 "[FC27] 변경분"처럼 덧붙인다).
